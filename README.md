# Marrakech-Safi Premium Tourism App

Premium academic full-stack tourism application for Marrakech-Safi.

## Stack

- React + Vite + TypeScript + Tailwind CSS + Motion + Lucide
- Node.js + Express + TypeScript
- MongoDB/Mongoose schemas with in-memory fallback data
- OpenWeatherMap weather proxy
- Budget calculator and trip planner APIs

## Run

```bash
npm install
npm run dev
```

Create `.env` from `.env.example` and add real API keys when needed. The weather widget and backend keep safe fallback data so the app works without keys during academic demos.
